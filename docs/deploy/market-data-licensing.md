# 주식 시세 재배포 문제 — 조사·판단·대응 (2026-11-19, 같은 날 4-1절 상세 조사 추가)

> 법률 판단이 아니다. 뉴스(네이버 검색 API) 약관 문제는 [`../naver-search-api-terms-issue.md`](../naver-search-api-terms-issue.md).
> 공개 자료 조사 결과이며, 출시 전 각 기관 답변과 전문가 확인으로 확정한다.

## 1. 결론
- FunNote 는 증권사 **개인용 API(KIS·키움)** 로 받은 시세를 **앱·웹의 모든 사용자에게 표시**한다. 확인한 조건들은 수익 여부가 아니라 **"제3자에게 보여 주는가(재배포)"** 를 기준으로 한다 → **광고를 빼도, 하루 1번 종가만 써도 계약이 필요할 가능성이 높다.**
- 이미 개발 서버(haezean)·상용 서버(funnotedaily)에서 공개 표시 중이다. **스토어 출시 전 해결**을 출시 조건으로 둔다.
- 장중 스냅숏·새 증권사 출처 추가는 이 문제가 정리될 때까지 **보류**.

## 1-1. 무엇이 문제이고 무엇이 아닌가 (사용자 확인 2026-11-19)
| 구분 | 시세 노출 대상 | 판단 |
|---|---|---|
| **관리자 웹**(주도주·5·20 정배열·조건검색·패턴·데이터 검증) | 운영자 본인만 | ✅ 본인 이용 — 유지 |
| 수집·계산 파이프라인, DB | 내부 | ✅ 유지 |
| **내 펀드** | 시세 아님 | ✅ 문제없음(사용자 확인) |
| **시황 해설 문장**(AI 요약·블로그 글, 핵심 지수·등락률 몇 개 인용) | 일반 사용자 | 🟢 위험 낮음(기사·리포트형 사실 인용) — 약관 문구로 확정은 아님, 문의 때 함께 확인 |
| 시황 + 주요 테마 등락률 몇 줄 | 일반 사용자 | 🟡 보통 |
| **사용자 웹·앱: 시장 탭·종목 상세·홈 시장 참고·특징주·급등락·수급 전광판(종목별 표)** | 일반 사용자 | 🔴 시세 재배포 — 계약 필요 |
| **트레이딩 게임**(실제 종목 실시간 시세)·차트 퀴즈 | 일반 사용자 | 🔴 계약 필요 |
| **블로그 글 안의 시세 차트 삽입** | 일반 사용자 | 🔴 시세 표시에 해당할 수 있음 |

- 광고를 없애도 해결되지 않는다: KRX(재배포 프로그램), 공공데이터(상업 여부 무관 재배포 금지), KIS(거래고객 대상 서비스 한정) 모두 기준이 **"제3자에게 보여 주는가"** 다.
- 장중 스냅숏이 아니라 **하루 1번 종가만 써도** 같은 문제다.
- 별개 규제: 시황 분석에 특정 종목 매수·매도 권유가 들어가면 **유사투자자문업** 문제가 될 수 있다 → "투자 권유가 아니에요" 고지 유지, 종목 추천보다 시장 흐름 해설 위주.

## 1-2. 무료·최소 비용으로 유지하는 방안
| # | 방안 | 비용 | 내용 |
|---|---|---|---|
| 1 | **KIS·키움 제휴 문의** | ~~0원 가능성~~ → **라이선스 비용은 별도**(11-19 확인) | KIS 제휴 안내 원문: "제휴기관은 KRX 및 해외거래소 시세정보를 이용하려는 경우 KRX 또는 해외거래소와 정보이용계약이 필요합니다", "법인(제휴사)이 … 코스콤과 정보이용계약 체결이 안 되어 있으면 API 를 이용해서 제휴사 브랜드 앱 화면으로 시세정보를 이용하는 것도 불가하다고 통보". 즉 제휴는 **전달 경로**일 뿐 거래소 라이선스를 대신하지 않는다. 제휴 대상도 "제3자에게 서비스를 제공하고자 하는 법인". 문의는 하되 0원 기대는 접는다 |
| 2 | **KRX 연간 구독**(앱 표시 승인 시) | 주식·지수 일별 기준 연 100만 원대 + 과거분 1회(상세는 안내서 원문) | 아래 3절 안내서 확인 결과 참고 — 이용 목적 승인·넥스트레이드 포함 여부가 관건 |
| 3 | **"사용자 시세 노출" 관리자 스위치** | 0원 | 끄면 사용자 웹·앱의 🔴 화면을 숨기고 안내·외부 링크로 대체, 관리자·수집은 그대로. 계약이 되면 켠다(Zero Deletion). 시황 해설 문장은 유지, 숫자 표·전광판·차트만 숨김. 게임은 가상·과거 차트 방식 여부, 블로그 차트 삽입 처리를 따로 결정 |
| 4 | 코스콤 시세 라이선스 | 견적 필요 | **법인만**. 업력 7년 미만 중소기업 기본료 36개월 면제 — 장중·실시간·게임까지 정식 |

권장: **1·2 문의를 동시에** → 결과 전까지 **3(노출 스위치)을 끈 상태로 출시 가능**하게 준비 → 계약되면 켠다.

### KRX Data Marketplace 상품 안내서(2026.10) 확인 결과
- 히스토리컬 데이터 판매 채널. **연간 구독형**은 매 거래일 오전 9시경 **직전 거래일(T-1)** CSV 를 이메일로 보냄(자동 갱신 없음, 무통장 입금).
- **이용 목적 제한**: 단순 복제·재분배로 수익을 내려는 구매는 받지 않음, 신청서의 이용 목적 외 사용 시 파기 요구·민사 책임 → **앱 표시 용도 승인 여부를 먼저 문의**.
- 확인 필요: **넥스트레이드 포함 여부**(KRX 단독이면 UN 통합 기준·MTS 일치 원칙과 다름), 부가세, 개인 명의 구매.
- 가격은 안내서 원문(재배포 금지 문서)에 있으므로 이 저장소에는 적지 않는다.

## 4. 권장 순서
0. **KIS·키움 제휴 문의**(0원 가능성) + 아래 KRX 문의를 함께.
1. **사업자 형태 확인** — 코스콤 오픈API 는 **법인만** 가능. 개인이면 1(KRX)·3(FnGuide) 쪽부터.
2. **KRX Data Marketplace 문의**(가장 먼저, 아래 문구) — 일별 시세 표시 라이선스 상품·비용.
3. **코스콤 문의**(법인이거나 법인 전환 계획이 있으면) — 일별 + 장중, 기본료 면제 적용 여부.
4. **FnGuide 문의** — 앱 표시(재배포) 가능한 상품이 있는지.
5. 견적 비교 → 결정 → 수집 파이프라인 출처 교체 설계(지금 KIS 일봉 단계를 새 공급원으로, MTS 일치 규칙·UN 통합 여부 재검증).
6. 결정 전까지: 장중 스냅숏·새 출처 보류, 광고 연동(AdSense·AdMob) 보류 권장.

### B. KRX 정보이용정책(2024-01-01, 코스콤 공표)에서 확인한 구조
외부제공권한 옵션 4개 중 우리에 맞는 것은 **[옵션 3] 웹사이트 체결가서비스용**:
- "웹사이트 및 모바일용 애플리케이션을 통해 일반대중에게 **호가 관련 정보(가격, 수량 등)를 제외한** 정보를 **조회 방식**으로 제공"
- "**사용자 수에 관계없이 정액제** 적용"(상품 브로셔) · 가입자 리포팅 의무 **없음** · 코스콤 요청 시 앱 URL·접속 ID 무상 제공(로그인·유료 서비스일 때)
- 금지: 사용자가 정보를 가공·저장·재분배할 수단(API·DDE 등) 제공, 전문가형 사용자 대상 서비스
- ⚠️ 확인할 것: 트레이딩 게임의 WebSocket 실시간 틱이 "조회 방식"으로 인정되는지(정책서는 스트리밍·자동 업데이트를 조회요청건과 구분함)

그 밖의 요금 요소:
- **시장대표지수 특수조건**(섹션 12): KOSPI·KOSPI200·KOSDAQ **3개만** 제공하면 리포팅 면제, 데이터피드도 사전승인 없이 허용 → 가장 가벼운 상품(정보상품 "KRX종합주가지수")
- **비조회형 정보이용**(섹션 8): "가공지표 산출", "계량분석", "포트폴리오관리" 등은 **별도 비조회형 이용료** → 실시간 데이터로 주도주·패턴·스크리너를 계산하면 추가 과금. **종가(Batch) 데이터로 계산하면 이 범주가 아님**(실시간정보 기준 정책)
- **종가 서비스**: 코스콤 "자본시장 종료 후 종가정보를 FTP 방식(Batch)으로 제공" — 실시간과 별도 상품
- 계약 주체: KRX 안내 "최초 이용사는 신청서와 **사업자등록증** 외에 추가 서류" → 개인사업자 가능성 있음(법인 한정은 **오픈API플랫폼**에만 명시). 문의로 확정
- 공개된 참고 요금(2014 코스콤 해명, 일반 정보사업자 기준): 유가증권 체결정보 월 150만, 코스닥 월 75만, 개인가입자 변동료 1인당 월 2,000원(5만 명까지) → 옵션 3 정액은 이와 다른 요금표. **금액은 문의로만 확인 가능**

### C. 기능별 "최소 비용" 단계 (어느 단계까지 사느냐로 기능을 고른다)
| 단계 | 사는 것 | 비용 | 켤 수 있는 기능 | 비고 |
|---|---|---|---|---|
| **0** | 없음 | 0원 | 내 펀드 · 시황 **해설 문장**(브리핑·마감 시황, 지수·등락률 몇 개 인용) · **DART 공시** 알림 · **ECOS 거시**(금리·환율·통화) · FRED · **정책브리핑** 기반 정책 이슈 · **가상 종목** 게임·차트 퀴즈 · 종목 **링크아웃**(증권사·포털) · 관리자 웹 전체(본인 이용) | 지금 KIS 로 수집·계산은 계속(운영자 본인 이용). 숫자 표·차트·전광판만 숨김 |
| **1** | 시장대표지수 3개(KRX종합주가지수) 또는 ECOS 802Y001(작성기관 확인 후) | 가장 가벼운 상품(금액 문의) / ECOS 면 0원 | 홈 **지수 카드**(코스피·코스닥·K200) · 시황 문장의 지수 숫자 정식화 | 리포팅 면제 |
| **2** | **종가·일별 데이터**: KRX Data Marketplace 연간 구독(T-1 CSV, 이용 목적 "앱 표시" 승인 필요) 또는 코스콤 종가 Batch | 연 100만 원대(안내서, 11-19 문서) / 코스콤은 문의 | 종목 상세 **일봉 차트** · 테마·업종 순위(이미 하루 1회) · **주도주·패턴·스크리너 결과 표시** · 급등락(**종가 기준**) · 수급 전광판(투자자별 상품 포함 여부 확인) · 과거 일봉 차트 게임 | 비조회형 이용료 범주 밖(실시간 아님). ⚠️ KRX 단독 데이터라 넥스트레이드 미포함 → "KRX 기준" 표기, MTS 와 거래량 차이 안내 |
| **3** | **옵션 3 웹사이트 체결가서비스**(증권A 유가 + 증권B 코스닥, 실시간 또는 지연) | 정액(금액 문의) | **장중 현재가** · 장중 급등락 · 실제 종목 실시간 게임(조회 방식 인정 시) | 호가 없음(우리는 안 씀). 사용자 수 무관 |
| ✗ | 호가 · 데이터피드 재분배 · 실시간 가공지표(비조회형) | 가장 비쌈 | — | 쓰지 않는다 |

**권장:** 단계 0 으로 출시 가능하게 노출 스위치를 만들고, **단계 2(종가)** 가격을 먼저 확인 — FunNote 의 핵심(시황 + 펀드 + 교육)은 종가 데이터로 거의 다 된다. 단계 3 은 게임을 실제 종목으로 되돌릴 때만.

### D. 함께 확인할 질문(문의 문구에 추가)

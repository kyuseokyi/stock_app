# 모바일 시황 & 스크리너 탭 UX/UI 설계 — 토스(Toss) 디자인 언어 적용

> **작성일**: 2026-10-30  
> **기준**: [`docs/mobile_design_language.md`](../mobile_design_language.md) (토스 스타일 파스텔 테마 C안)  
> **목적**: 기존 스크리너 탭에 과도하게 몰려 있던 지수/히트맵/테마/일정을 분리하고, 모바일 하단 탭(Bottom Tabs)을 토스 디자인 원칙에 맞추어 최적화

---

## 1. 모바일 하단 탭(Bottom Tabs) 구조 결정

### 1.1 하단 탭바 제약 조건 및 토스 원칙
* **모바일 폭 한계 (360~390px)**: 하단 탭에 6개 이상을 배치하면 아이콘과 텍스트의 터치 타깃(최소 44px)이 좁아지고 라벨이 잘려 토스 원칙인 **"과감한 여백(Breathing room)"**과 **"큰 탭 타깃"**을 해칩니다.
* **최적 탭 개수**: **5개 고정**

### 1.2 최종 탭 구성: `홈` · `시황` · `스크리너` · `게임` · `내정보`

커뮤니티(블로그) 피드는 **홈 탭의 메인 콘텐츠**로 통합 흡수(토스/인스타그램 스타일: 홈 화면 자체가 피드)하고, 투자 앱의 핵심 기능인 **[시황]**과 **[스크리너]**를 당당히 하단 메인 탭으로 전진 배치합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        모바일 하단 탭바 (5개)                          │
├─────────────┬─────────────┬─────────────┬──────────────┬───────────────┤
│    [홈]     │   [시황]    │ [스크리너]  │    [게임]    │   [내정보]    │
│ home-outline│pulse-outline│search-outline│game-control  │ person-outline│
└─────────────┴─────────────┴─────────────┴──────────────┴───────────────┘
```

> **비고**: 기존 `blog`(커뮤니티)는 홈 탭 상단의 추천글 및 게시판 칩으로 연결되어 접근성이 보장되며, 하단 탭은 실제 투자자들이 가장 매일 자주 확인하는 **시황(Market)**과 **스크리너(Screener)**가 각각 독립적인 공간을 갖습니다.

## 2. 화면별 상세 UI/UX 명세 (토스 디자인 가이드 준수)

### 2.1 [시황 탭] `mobile/src/app/(tabs)/market.tsx`

> **컨셉**: "한눈에 파악하는 오늘의 시장 돈의 흐름 (Top-down)"  
> **배경**: `theme.colors.background` (연한 라벤더) / 카드는 모두 `surface` (흰색)

#### ① 헤더 & 장운영 배너
* 상단 큰 타이틀: **"오늘의 증시"** (`Title`, 24px, 700)
* 우측: 기준일 및 갱신 시간 (예: `10.30 11:30 기준`)
* KIS 장운영 상태에 따른 서브 뱃지 (`[정규장]`, `[장마감]`, `[VI 발동]`)

#### ② AI 모닝 글로벌 브리핑 카드 (`surfaceBlue` 배너 토큰 적용)
* 토스 디자인의 **블루 안내 배너 (`surfaceBlue` 배경 + 둥근 모서리 R20)** 적용
* 구성:
  * 배지: `AI 장전 브리핑 (08:30)`
  * 굵은 헤드라인: *"미 증시 빅테크 랠리에 나스닥 +1.4%... 오늘 국장 반도체 강세 출발 예상"*
  * 터치 시: 바텀시트(Bottom Sheet)로 펼쳐져 **[수혜 예상 섹터]**, **[주의 섹터]**, **[환율/금리 체크포인트]** 상세 확인

#### ③ 주요 지수 미니 카드 (가로 스크롤 캐러셀)
* 국내: 코스피, 코스닥 / 해외: 나스닥, S&P500, 필라델피아 반도체, 원/달러 환율
* 카드 규격: 가로 140px, 세로 90px 흰색 카드 (`surface`)
* 표시: 지수명, 현재 지수, 등락률(`up` 핑크레드 / `down` 블루), 미니 추세선 (`react-native-svg` 스파크라인)

#### ④ 시장 히트맵 (업종 & 테마 트리맵)
* 상단 토글 칩: `[시가총액 기준]` `[거래대금 기준]` (Pill 토큰)
* 면적: 화면 가로 100% (좌우 패딩 20px 제외), 높이 220px
* 색상: 상승(`up` 파스텔 핑크레드), 하락(`down` 파스텔 블루)
* 터치 인터랙션: 섹터 박스 터치 시 하단 바텀시트로 **"해당 섹터 소속 종목 랭킹 Top 5"** 즉시 표출

#### ⑤ 실시간 급등락 & AI 원인 분석기
* 상단 탭 전환: `[급등 Top 10]` `[급락 Top 10]`
* 구분선 없는 리스트 (여백 16px 기반 위계)
* 항목:
  * 1열: 순위(1~10) 및 종목명 + 현재가 + 등락률
  * 2열: **AI 1줄 원인 칩 (`fill` 배경)**: *"HBM3E 공급 승인 단독보도로 외인 2,000억 순매수"*
  * 3열: 재료 성격 태그 (`[수주계약]`, `[실적호조]`, `[테마]`)

#### ⑥ 테마 랭킹 & 핫 키워드 워드칩
* 핫 키워드: 가로 스크롤 Pill 칩 (`#HBM`, `#방산수출`, `#비만치료제`)
* 테마 랭킹 리스트: 테마명, 평균 등락률, 대장주 이름 및 등락률

#### ⑦ 증시 캘린더 요약
* "이번 주 다가오는 일정 3건" (공모주 청약, FOMC 등)

### 2.2 [스크리너 탭] `mobile/src/app/(tabs)/screener.tsx`

> **컨셉**: "조건으로 발굴하는 똑똑한 알짜 종목 (Bottom-up)"  
> **특징**: 시장 지표는 모두 시황으로 넘어가고 오직 **"종목 필터링과 AI 검증"**에만 집중

#### ① 상단 필터 칩 (세그먼트 알약형)
* `[주도주 (CANSLIM)]` `[차트 패턴]` `[추천 프리셋]` `[커스텀 필터]`

#### ② 주도주 (CANSLIM) 결과 뷰 + AI 지뢰 감지 뱃지
* 종목 카드 구성:
  * 종목명, 티커, 현재가, RS 등급 (예: `RS 92`)
  * 통과 항목 배지: `C` `A` `N` `S` `L` `I` `M`
  * **[신규 AI 카드 영역]**:
    * **포착 사유**: *"수출 단가 인상에 따른 본업(영업이익 +120%) 중심 성장"*
    * **지뢰 감지 뱃지**: `CLEAN (안전)` (초록) 또는 `WARNING (CB 전환물량 12% 대기)` (주황)
* 터치 시: 모바일 종목 상세/차트 화면으로 부드럽게 네비게이션

#### ③ 차트 패턴 (VCP) 결과 뷰
* VCP 변동성 축소 단계 표시 (`Base 1 - 3T`)
* 피봇 돌파 기준가 및 현재가와의 이격도

## 3. 코드 변경 가이드 (모바일 프론트엔드)

### 3.1 하단 탭 레이아웃 수정 (`mobile/src/app/(tabs)/_layout.tsx`)
```tsx
// 1. 시황(market) 탭 추가
<Tabs.Screen
  name="market"
  options={{
    title: '시황',
    tabBarIcon: ({ color, size }) => (
      <Ionicons name="pulse-outline" color={color} size={size} />
    ),
  }}
/>

// 2. 스크리너(screener) 탭 아이콘 및 타이틀 정비
<Tabs.Screen
  name="screener"
  options={{
    title: '스크리너',
    tabBarIcon: ({ color, size }) => (
      <Ionicons name="search-outline" color={color} size={size} />
    ),
  }}
/>
```

### 3.2 신규 라우트 파일 추가
* `mobile/src/app/(tabs)/market.tsx` : 시황 대시보드 메인 화면
* `mobile/src/features/market/` : 기존 스크리너에서 시황 관련 컴포넌트(`IndexCards`, `TreeMap`, `MoversList`, `MorningBriefCard`) 이관

## 4. 검증 체크리스트
- [ ] 5개 탭의 너비가 360px 기기(작은 안드로이드)에서도 텍스트 잘림 없이 표시되는지 확인
- [ ] 토스 파스텔 C안 컬러 토큰(`background`, `surface`, `surfaceBlue`, `up`, `down`, `accent`) 준수 여부
- [ ] 탭 선택 시 `accent`(핑크 포인트) 하이라이트 정상 작동 확인

# 마켓 탭 '오늘 특징주' 카드 — 신고저가 + VI 발동 (2026-11-17)

키움 연동 ④-4. 사용자 결정(2026-11-17): 범위 = **신고저가 + VI**, 위치 = **마켓 탭** 카드(웹·앱).

## 데이터
1. **52주 신고가·신저가** — 키움 없이 우리 일봉(`daily_prices` FINAL, UN 기준)으로 계산. 개발·상용 모두.
   - 기준: 당일 고가 > 직전 251거래일 최고가 → 신고가, 당일 저가 < 직전 251거래일 최저가 → 신저가. 스크리너의 기존 `is_new_high` 계산(`apps/collector/screener/compute.py`)이 있으면 **재사용**(같은 정의). 신저가는 대칭으로 추가.
   - 유니버스: 보통주(ETF·스팩·우선주 제외 — 기존 유니버스 필터 재사용), 상장 252거래일 미만 종목 제외.
   - 정렬: 당일 등락률 내림차순(신저가는 오름차순), 각 상위 N(기본 20) + 전체 개수.
   - 시점: 20:30 파이프라인(일봉 확정 뒤) 단계 `featured_highs` → Redis/CH 스냅숏. 장중에는 직전 거래일 결과를 "어제 기준"으로 표시.
2. **VI 발동** — 키움 `ka10054`(변동성완화장치발동종목요청). 상용(키 있음)만.
   - 장중(09:00~15:30, 거래일) **5분마다** 호출 → 오늘 발동 목록(종목·이름·발동 시각·정적/동적·발동가·괴리율 등 명세 필드)을 Redis 에 저장(당일 키, TTL 2일). 같은 종목 여러 번이면 최근 시각·횟수.
   - 경로·body·응답 키·필드·연속조회·시간 제한은 **명세 확인 + 소량 실측**(`probe --vi`).
   - 키 없음·실패 → VI 칸을 응답에서 빼고(`vi: null`) 화면은 그 칸을 숨긴다. 신고저가는 그대로.
   - 호출량: 하루 약 80회(+연속조회). 실패가 연속되면 그날 남은 호출 중단(헛호출 방지).

## API·화면
- REST `GET /api/v1/market/featured` → `{date, highs:{count, items[]}, lows:{count, items[]}, vi:{updated_at, count, items[]}|null}`. 항목 `{ticker, name, close, change_rate, ...}`. Router → Service → Repository.
- 웹(`web_client`)·앱(`mobile`) 마켓 탭에 '오늘 특징주' 카드: 탭(신고가 / 신저가 / VI) + 상위 목록, 종목 누르면 종목 상세. 디자인은 기존 마켓 카드·토스식 기준(`docs/mobile_design_language.md`). 빈 상태 문구("오늘 신고가 종목이 없어요" 등), VI 칸은 데이터 없으면 숨김.

## 하지 않는 것
VI 푸시 알림, 장중 신고가 실시간 계산, 과거 특징주 이력 화면, 홈 화면 노출.

## 테스트
신고가/신저가 판정(경계·252일 미만 제외·유니버스), 정렬·상위 N, ka10054 body·정규화·장중 시간 판정·연속 실패 중단, 키 없음 → vi null, API 응답 구조, 웹·앱 카드 렌더(빈 상태·VI 숨김).

## 반영
배포 → 상용 `probe --vi`(장중) 실측 → 다음 20:30 이후 신고저가 확인, 장중 VI 확인. 문서: `docs/data-collection.md`, `docs/kiwoom_setup_and_dev_spec.md`(④-4), README.

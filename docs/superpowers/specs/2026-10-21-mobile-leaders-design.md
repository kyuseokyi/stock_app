# 모바일 주도주(CANSLIM) 탭 + 종목 상세 설계

- 작성: 2026-10-21 · 상태: 승인(사용자 "응 계속 진행해줘" — 2번은 추천안: 범용 종목 상세 + 그룹 상세 진입 포함)
- 선행: CANSLIM 설계 `2026-10-18-canslim-design.md`(웹·서버), 모바일 스크리너 설계 `2026-10-20-mobile-screener-design.md`(§7 다음 단계 1·3번이 이 문서)

## 1. 목표와 범위

웹 `/screener/leaders` 의 주도주 분석을 모바일 스크리너 탭에 옮긴다. **백엔드 변경 없음** — 공개 GraphQL `canslimMarket`·`canslimScreen`·`canslimScore`·`getChartData` 를 그대로 쓴다.

**범위**: 스크리너 '주도주' 칩, 목록(시장 방향·정렬·필터 바텀시트·무한 스크롤), 범용 종목 상세 라우트(점수표·일봉 차트·점수 추이), 테마·업종 상세의 구성 종목 → 종목 상세 이동.
**범위 밖**: 차트 드로잉, 새로 통과한 종목 알림, 관심 종목, 서버 변경.

## 2. 화면

### 2.1 스크리너 '주도주' 칩 (`LeadersSection`)
- 칩 순서: 시장 · 테마 · 업종 · 일정 · **주도주**(웹 탭 순서와 같음).
- 상단 **시장 방향 줄**: KOSPI·KOSDAQ 각각 상태(상승 추세/조정/하락 — 색은 테마 up/down/중립)·분산일 n일. 아래 작은 글씨 "기준일 종가 · 매일 20:30 갱신 · 투자 권유가 아닙니다". 지수 데이터가 없으면 "지수 데이터를 모으고 있어요".
- **정렬 칩**: 점수 · RS · 통과 수. 오른쪽 **[필터]** 버튼(적용 중인 필터 수 배지).
- **필터 바텀시트**: 시장(전체/KOSPI/KOSDAQ), 최소 통과 수(전부·3~7개 이상), 꼭 통과할 항목 C~M 토글, 거래 활발 종목만(기본 켬). [적용]·[초기화]. 기본값은 웹 `DEFAULT_FILTERS` 와 같음.
- **목록**(FlatList): 총 n개. 행 = 점수 상자 · 종목명/티커 · C~M 배지 7개 · 업종(없으면 시장) · RS · 종가 · 고점 대비 %. 50개씩 `onEndReached` 로 이어 받기(offset). 당겨서 새로고침.
- 상태: 오류(다시 시도), 로딩, `date === null` → 🛠️ "분석 데이터를 준비하고 있어요 / 매일 장 마감 후 계산돼요", 0건 → "조건에 맞는 종목이 없어요 / 필터를 줄여 보세요".
- 행을 누르면 `/stock/[ticker]`.

### 2.2 종목 상세 `/stock/[ticker]` (범용)
- 헤더: 종목명(없으면 티커). 본문 스크롤:
  1. 머리: 이름·티커·업종(시장)·종가·기준일, 점수 상자, "7개 중 n개 통과".
  2. **일봉 차트**: 최근 약 1년, 50일 이동평균선, 52주 고점 점선(`high52w` — 종가와 N 값으로 역산, 값 없으면 생략).
  3. **7항목 점수표**: 배지 · 이름 · 상태 글자(통과/미달/데이터 부족/준비 중) · 서버 `display` · `explanation` · "기준: threshold".
  4. **점수 추이** 미니 그래프(react-native-svg, 점 2개 미만이면 숨김).
  5. 안내: "실적(C·A)은 최신 공시 기준이며, 투자 권유가 아닙니다."
- `canslimScore` 가 null(ETF·우선주 등 분석 비대상) → 일봉 차트는 보여주고 점수 영역 대신 "주도주 분석 대상이 아니에요(보통주만 분석해요)".
- 차트만 실패하면 차트 자리에 짧은 오류, 점수 영역은 정상 표시(서로 독립 조회).

### 2.3 그룹 상세 → 종목 상세
- `app/market/[kind]/[id].tsx` 의 구성 종목 행을 누르면 `/stock/[ticker]`(현재는 누를 수 없음).

## 3. 차트
- 게임의 lightweight-charts WebView(`TvChart` + `chart-bridge` + `chart-page`)를 재사용.
- 이동평균 기간을 **선택 인자**로 받게 확장(기본 5·20·60 유지 → 게임 화면 영향 없음). 주도주 상세는 `[50]`.
- 52주 고점은 기존 `lines`(`dashed: true`, title '52주 고점').
- 컴포넌트 위치(게임 폴더 → 공용)를 옮길지는 계획에서 최소 변경으로 정한다(옮기지 않고 import 해도 됨).

## 4. 코드 구성
- `mobile/src/features/leaders/`: `api.ts`(`export const ..._QUERY` 문자열 — 계약 테스트 대상), `types.ts`, `canslim.ts`(웹 `lib/canslim.ts` 의 순수 함수 이식, 색은 테마 키로), `use-canslim-screen.ts`(필터·페이지·새로고침), `use-canslim-score.ts`, `components/`(letter-badges·market-strip·leader-row·filter-sheet·score-table·score-history·stock-daily-chart), `sections/leaders-section.tsx`.
- 라우트 `mobile/src/app/stock/[ticker].tsx`.
- 백엔드 계약 테스트 `backend/tests/test_market_query.py` 에 모바일 주도주 쿼리 파일 경로를 추가해 실제 스키마로 실행되게 한다(백엔드 코드 변경 아님).

## 5. 테스트
- 모바일 jest(순수 로직): `canslim.ts`(상태 글자·52주 고점·필수 항목 토글·적용 필터 수), 화면 상태 판정(준비 중·0건·비대상), 무한 스크롤 페이지 병합.
- 백엔드: 계약 테스트가 모바일 쿼리 문자열을 실제 스키마로 실행.
- 실기기(사용자): 칩 → 목록·필터·정렬·더 불러오기, 행 → 상세(차트·점수표), 그룹 상세 구성 종목 → 상세, ETF 비대상 표시.

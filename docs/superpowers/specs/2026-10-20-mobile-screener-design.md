# 모바일 스크리너 탭 설계 — 시장 · 테마 · 업종 · 일정 (2026-10-20)

웹 스크리너(`/screener`, 5탭)를 모바일 앱으로 옮기는 **1차** 설계. 서버(stock_api GraphQL)는 그대로 쓰고 모바일 화면만 만든다.
배경: 2026-10-08 화면 구조 재설계([`2026-10-08-mobile-screen-architecture-design.md`](2026-10-08-mobile-screen-architecture-design.md))에서
미구현 플레이스홀더였던 스크리너 탭을 뺐고, "추후 별도 진입점으로 부활 가능"으로 남겨 두었다. 이번에 하단 탭으로 되살린다.

## 1. 결정 사항

| # | 질문 | 결정 |
|---|---|---|
| D1 | 1차 범위 | **시장 · 테마 · 업종 · 일정** 4가지. 주도주(CANSLIM)는 2차로 별도 설계 |
| D2 | 진입점 | **하단 탭 추가** — 홈 · 커뮤니티 · 게임 · **스크리너** · 내정보(웹 메뉴와 같은 순서) |
| D3 | 테마·업종 트리맵 | **이번엔 목록 + 상세만.** 트리맵은 다음 단계 |
| D4 | 구현 방식 | **모바일 전용 화면(A안)** + 지수 카드 미니 추세선은 `react-native-svg` |

검토했지만 고르지 않은 방식: 미니 추세선 없이(B — 결국 다시 넣게 됨), 웹 스크리너를 웹뷰로(C — 웹 헤더·메뉴가 앱 안에 보이고 다크 모드·앱 디자인을 못 따라감).

## 2. 화면 구성

### 2-1. 하단 탭
- `(tabs)/_layout.tsx` 에 `screener` 탭 등록, 위치는 게임과 내정보 사이. 제목 "스크리너", 아이콘 `stats-chart-outline`.

### 2-2. 스크리너 탭 (`src/app/(tabs)/screener.tsx`)
맨 위 칩 **시장 · 테마 · 업종 · 일정** — 칩을 누르면 같은 화면 안에서 내용만 바뀐다(커뮤니티의 게시판 칩과 같은 방식).
모든 칩 화면은 당겨서 새로고침, 맨 아래 기준일 안내("기준일 · 매일 장 마감 후 갱신 · 투자 권유가 아닙니다").

| 칩 | 내용 |
|---|---|
| **시장** | ① 지수 카드 — 국내(코스피·코스닥·코스피200)와 미국 지수·환율, 2열. 카드마다 종가·등락률·**미니 추세선**. ② 거시 지표 카드(FRED, 데이터 있을 때만). ③ **주도 테마 Top 5** — "더 보기" → 테마 칩. ④ **다가오는 일정 3건** — "더 보기" → 일정 칩. 웹의 업종 지도(트리맵)는 제외 |
| **테마 / 업종** | ① 조건 칩: 기간(1일·5일·20일), 정렬(등락률·거래대금). ② 순위 목록 30개씩, 끝까지 내리면 30개 더. ③ 한 줄: 순위, 이름, 등락률(상승 `up`·하락 `down` 색), 상승·하락 종목 수 막대, 대장주 이름·등락률, 연속 상위 표시. ④ 누르면 그룹 상세 |
| **일정** | ① 분류 칩: 전체·공모주·경제지표. ② 앞으로 60일 일정을 날짜별로 묶어 표시(공모주는 "종목명 (티커)" + 공모가·주관사). ③ 지난 7일은 "지난 일정 보기"로 펼침 |

### 2-3. 그룹 상세 (`src/app/market/[kind]/[id].tsx`, `kind` = `theme` | `sector`)
- 루트 `_layout.tsx` 에 상단 뒤로 가기 헤더와 함께 등록(제목 = 그룹 이름).
- **요약**: 1·5·20일 등락률, 거래대금, 시가총액, 상승·하락·보합 종목 수, 현재 순위.
- **구성 종목**: 종목명, 종가, 1·5일 등락률, 대장주 표시, 편입 사유(있을 때).
- 순위 변화 이력 그래프는 넣지 않는다.

### 2-4. 이번 범위 밖
트리맵(업종 지도), 주도주(CANSLIM) 탭, 종목 상세·일봉 차트(종목을 눌러도 이동하지 않음), 순위 이력 그래프.

## 3. 코드 구조

### 3-1. 새 기능 폴더 `mobile/src/features/market/`
| 파일 | 역할 |
|---|---|
| `types.ts` | 웹 `web_client/src/types/market.ts` 와 같은 타입(지수·거시 지표·그룹 순위·그룹 상세·일정) |
| `api.ts` | GraphQL 조회 4개 — 시장 개요(`MarketOverview`), 그룹 순위(`MarketGroups`), 그룹 상세(`MarketGroup`), 일정(`MarketCalendar`). 웹 `api/market.ts` 와 같은 쿼리 문자열을 기존 `stockRequest` 로 보낸다(조회 재시도·진행 표시줄은 이미 붙어 있음) |
| `format.ts` | 순수 함수 — 금액 줄여 쓰기("1.2조"·"3,400억"), 등락률 부호·색 선택, 미니 추세선 좌표 계산, 일정 나누기·날짜별 묶기, 순위 이어 붙이기·끝 판정 |
| `use-market-overview.ts` | 시장 칩: 개요·주도 테마 Top 5·다가오는 일정 3건을 **따로** 불러옴(하나가 실패해도 나머지는 보임) |
| `use-group-ranking.ts` | 테마·업종 칩: 기간·정렬 조건, 30개씩 더 불러오기, 요청 번호로 늦은 응답 무시 |
| `use-group-detail.ts` | 그룹 상세 |
| `use-calendar.ts` | 일정 칩: 분류 조건, 앞으로 60일·지난 7일 |
| `components/` | `index-card`, `sparkline`, `group-row`, `breadth-bar`, `event-list`, `basis-note` |

훅은 모두 처음 불러오기 `reload`(전체 로딩) / 당겨서 새로고침 `refresh`(기존 내용 유지, 성공 시 교체) 두 가지를 주고,
화면에서 공용 `usePullRefresh`(`src/hooks/use-pull-refresh.ts`)와 연결한다.

### 3-2. 미니 추세선
- `react-native-svg` 의 `Polyline` 하나. 서버가 주는 `spark: number[]` 를 0~100 좌표로 바꿔 그린다(웹 `IndexCards` 와 같은 방식).
- 색: 마지막 값 ≥ 첫 값이면 `up`, 아니면 `down`. 좌표 계산은 `format.ts` 순수 함수.
- 패키지 설치는 **사용자가 직접**(작업 규칙: 앱에서 `npm install` 금지): `cd mobile && npx expo install react-native-svg`.
  네이티브 패키지라 설치 후 개발용 앱 재빌드 — `APP_ENV=development npx expo run:android --port 8082`.

### 3-3. 바꾸지 않는 것
서버(stock_api GraphQL), 웹(web_client), 기존 모바일 탭 화면.

## 4. 오류·빈 상태

| 상황 | 처리 |
|---|---|
| 처음 불러오는 중 | 가운데 "불러오는 중…". 다시 불러올 땐 기존 내용 유지 + 위쪽 스피너 |
| 시장 칩 지수 개요 실패 | "시장 데이터를 불러오지 못했어요" + [다시 시도] + 오류 코드, 당겨서 새로고침 가능 |
| 시장 칩 주도 테마·일정만 실패 | 지수 카드는 보이고 실패한 칸만 숨김 |
| 지수 데이터 없음(수집 전) | "시장 데이터를 준비하고 있어요 · 매일 장 마감 후 갱신돼요" |
| 미니 추세선 점 2개 미만 | 선 숨기고 숫자만 |
| 거시 지표 비어 있음 | 거시 지표 칸 통째로 숨김 |
| 테마·업종 순위 없음 | "아직 집계된 테마가 없어요 · 매일 장 마감 후 갱신돼요"(업종이면 "업종") |
| 더 불러오기 실패 | 목록 유지 + 맨 아래 "더 불러오지 못했어요 · 다시 시도" |
| 그룹 상세 없음(사라진 테마 등) | "이 그룹 정보를 찾을 수 없어요" + 뒤로 가기 |
| 일정 없음 | "앞으로 60일 안에 잡힌 일정이 없어요" |
| 당겨서 새로고침 실패 | 화면 유지 + "새로고침하지 못했어요" 알림(공용 방식) |
| 기간·정렬 칩을 빠르게 바꿈 | 요청 번호를 매겨 **마지막 요청의 응답만** 반영 |

## 5. 테스트·확인

- **jest(순수 함수)**: 금액 줄여 쓰기(1조 이상·1억 이상·그 아래), 등락률 부호·색(null → "–"), 미니 추세선 좌표(평평한 선·점 1개·빈 배열),
  일정 60일/지난 7일 나누기·날짜별 묶기·"오늘" 표시, 순위 이어 붙이기 중복 제거·끝 판정(받은 수 < 30 또는 total 도달), 늦은 응답 무시.
- **타입 검사** `npx tsc --noEmit`, 전체 `npx jest`.
- **실기기(SM-A536N)**: 스크리너 탭 표시, 칩 4개 전환, 테마 → 그룹 상세, 더 불러오기, 당겨서 새로고침, 다크 모드. 데이터는 haezean 개발 서버.

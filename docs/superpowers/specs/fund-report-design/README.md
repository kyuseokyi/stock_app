# 펀드 리포트 화면 시안 (2026-10-18)

데이터는 테스트용 가린 픽스처(`mobile/src/features/fund/__fixtures__/current.json`) — 실제 값 아님.
브라우저로 HTML 파일을 직접 열어 본다.

| 파일 | 내용 |
|---|---|
| `variants.html` | A·B·C 시안. 위쪽 탭으로 전환(`?v=a|b|c`) |
| `compare.html` | 세 시안을 휴대폰 폭(375px)으로 나란히 |
| `compare-375.png` | 위 비교 화면 캡처 |
| `simple-v1.html` | 첫 심플 샘플(카드 안 정렬 기준선이 둘이라 탈락). `?check` 로 포맷 점검표 |

## 시안
- **A. 명세서 표** — 계좌=열, 항목=행. 계좌 간 비교가 가장 쉽지만 휴대폰에서 계좌 2개↑면 가로 스크롤.
- **B. 정렬 그리드 카드 (채택)** — 카드 전체를 `grid-template-columns: 1fr auto` 하나의 격자로. 큰 금액까지 같은 오른쪽 기준선.
- **C. 요약 목록(토스형)** — 계좌별 한 줄 요약(이름 / 평가금+수익률), 눌러서 상세. 가장 간단하지만 세부는 한 번 더 눌러야 함.

## 표시 포맷 규칙 (세 시안 공통, 원본 값은 그대로 두고 화면에서만)
- 금액: 천 단위 쉼표 + `원`(작게). `₩` 접두는 떼고 `원`으로 통일. 음수는 `−`(U+2212).
- `+`/`−` 부호: 손익·입출금·수익율(목표값 제외). 상승/하락 색: 손익·수익율만(입출금은 색 없음).
- 퍼센트: 소수 2자리 반올림(원본은 마우스 올리면 title 로 표시).
- 날짜: `YYYY.MM.DD`. 경과일수: `N일`. CODE·그룹 구분코드: 그대로(상세로 접음).
- 숫자는 모두 오른쪽 정렬 + `tabular-nums`.

# 게임 차트 보조지표(이동평균선·볼린저밴드) 설계 스펙

> 작성일: 2026-10-14 · 상태: 승인됨(사용자: "차트에 보조지표도 추가 해줘 이동평균선과 볼린저밴드만 있으면 될것같아" → 선택 "이대로 진행")

## 1. 지표
- 이동평균선(SMA) 5·20·60 — 종가 기준. 일봉이면 5/20/60일, 분봉이면 해당 단위 캔들 5/20/60개.
- 볼린저밴드 20, 2σ — 중심=SMA20, 상단/하단=중심 ± 2×모표준편차(population, MTS 관례).
- 기간보다 캔들이 적은 구간은 값 없음(선이 그 지점부터 시작).
- 일봉 조회 범위(180일 ≈ 120거래일)로는 120일선이 거의 안 그려져 제외.

## 2. 계산 위치
- 서버 변경 없음. web·mobile 이 받은 캔들(일봉·분봉 공통)로 직접 계산 — 순수 함수 `lib/indicators.ts`.
- 실시간 틱으로 마지막 캔들이 바뀌면 마지막 지표 값도 다시 계산.
- mobile 은 화면에 최근 60개만 그리지만 계산은 받은 전체 캔들로 해서 첫 캔들부터 선이 이어지게.

## 3. UI
- 단위 칩 줄 옆(오른쪽)에 토글 칩 `이동평균`·`볼린저`. 기본: 이동평균 켜짐, 볼린저 꺼짐. 화면 상태로만 유지(관리자 설정 없음).
- 이동평균이 켜져 있으면 차트 왼쪽 위에 범례 `5 · 20 · 60`(선 색).
- web(lightweight-charts): 선 시리즈 6개(MA 3 + BB 3), BB 중심선은 점선, 상·하단 사이 옅은 채움(시리즈 primitive). 가격 축 라벨·마지막 값 라벨은 숨김(가격선 라벨과 겹치지 않게).
- mobile(View 차트): 점 사이를 회전한 1px View 선분으로 이은 꺾은선. 가격 범위 계산에 켜진 지표 값 포함(선이 차트 밖으로 나가지 않게).
- 진입가·손절·익절·지지·저항선은 그대로.

## 4. 검증
- mobile jest: sma·bollinger(경계·null 구간·값), 선분 좌표.
- web tsc·build. 로컬 브라우저에서 일봉·분봉 토글 확인.

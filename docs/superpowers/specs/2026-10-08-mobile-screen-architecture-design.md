## 1. 배경 & 목표

지금 모바일 앱은 **콘텐츠 큐레이션 중심**(추천글 홈 + 게시판)이며 스크리너·관심종목은 미구현 플레이스홀더다. 신규 플래그십 기능 **실시간 가상 트레이딩 게임**("게임 80% + 교육 20%")이 들어오면서, 게임을 중심축으로 **앱 전체 네비게이션을 재설계**한다.

**이 문서의 범위**: 앱의 화면/탭 구조, 각 화면의 정보 구성, 로그인/게스트 경계, 게임 탭의 진입·부가기능 배치. 트레이딩 게임의 **백엔드·실시간 체결·WS 프로토콜은 범위 밖**(Phase 1~5 별도 스펙). 각 화면의 **픽셀 단위 비주얼**도 범위 밖(디자인 언어 문서가 규정).

**성공 기준**
1. 하단 4탭 구조(홈·블로그·게임·내정보)로 재편되고 스크리너·관심종목 탭이 제거된다.
2. 게임 탭이 "플레이 직행 + 바텀시트 부가기능" 형태로 자리를 잡는다.
3. 비로그인 둘러보기 / 간편로그인 게이팅 경계가 모든 화면에서 일관된다.
4. 모든 신규 화면이 토스 디자인 언어 토큰·컴포넌트를 사용한다.

### 열린 결정(기본값으로 진행, 구현 전 재확인)
- **O1 홈 상단 "내 순위 배너"**: 기본 = **노출**(로그인 시 내 순위, 비로그인 시 "간편로그인하고 시즌 참가하기" CTA).
- **O2 간편로그인 제공자**: 기본 = **카카오 + Apple**(iOS 심사 요건), Google은 2순위. → auth 백엔드 `POST /api/v1/auth/social` 연동 스펙에서 확정.
- **O3 다크모드**: 기본 = **OS 자동 유지**(현행 `adaptiveThemes`). 트레이딩 플레이 화면도 동일 테마 토큰 사용(별도 다크 집중 모드 없음).
- **O4 Pretendard 폰트 동봉**: 기본 = **동봉**(expo-font). 미동봉 시 시스템 폰트 폴백.

## 3. 네비게이션 아키텍처

### 3.1 탭 구조 (expo-router `(tabs)`)
```
app/
  _layout.tsx                 # 루트 스택: (tabs) + blog/[id] + (추가) game 모달 라우트
  (tabs)/
    _layout.tsx               # 하단 4탭: index(홈) / blog / game / profile
    index.tsx                 # 🏠 홈 — 추천글 피드 (+ 내 순위 배너 O1)
    blog.tsx                  # 📰 블로그 — 게시판 목록
    game.tsx                  # 🎮 게임 — 트레이딩 플레이 화면(직행)
    profile.tsx               # 👤 내정보 — 플레이어 마이페이지
  blog/[id].tsx               # 글 상세 (기존, 탭 밖 스택)
```
- **제거**: `(tabs)/screener.tsx`, `(tabs)/watchlist.tsx` 및 탭 등록. (스크리너는 "최후 구현" 방침과 일치 — 추후 별도 진입점으로 부활 가능)
- 탭 아이콘/라벨: 홈 `home`, 블로그 `newspaper`, 게임 `game-controller`(또는 `trending-up`), 내정보 `person`. 활성색 = `theme.colors.primary`.

### 3.2 게임 부가기능 = 바텀시트 (탭 아님)
랭킹/지인리그/퀘스트/야간퀴즈는 **탭도 라우트 화면도 아닌** 게임 플레이 화면 위의 바텀시트로 띄운다. (expo-router 모달 라우트 또는 `@gorhom/bottom-sheet` 등 — 구현 단계에서 라이브러리 선정)

## 4. 화면별 구성

### 4.1 🏠 홈 (`(tabs)/index.tsx`) — 기존 확장
- 상단: **내 순위 배너**(O1) — 로그인 시 `시즌N · 내 순위 24위 · +24.5%`(탭하면 게임 탭 이동), 비로그인 시 "간편로그인하고 시즌 참가하기" CTA.
- 본문: **추천글 피드**(현행 `useFeaturedPosts` 유지). 카드 탭 → `blog/[id]`.
- 게스트 열람 OK. 디자인: 큰 타이틀 + 토스 카드/리스트.

### 4.2 📰 블로그 (`(tabs)/blog.tsx`) — 기존 유지
- 게시판 칩(board chips) + 글 목록 + 페이지네이션(현행). 글 → `blog/[id]`(WebView 상세 + 댓글).
- 게스트 열람 OK. 댓글 작성 등 쓰기 동작은 간편로그인 요구(기존 401 → 로그인 유도 흐름 재사용, 단 로그인 UI는 간편로그인으로 교체).

### 4.3 🎮 게임 (`(tabs)/game.tsx`) — 신규 (Phase 6 와이어프레임)
플레이 직행. 구성(위→아래):
1. **헤더**: `시즌N 종목(코드) · 종료 D-x · 내 순위 / 수익률`, 자본금, 우측 상단 아이콘 `🏆 랭킹 · 🤝 지인리그 · 🎯 퀘스트`.
2. **코치 가이드 배너**(접기 가능): 관리자 데일리 코칭 문구.
3. **유저 베팅 심리 미터**: Long/Short 비율 바.
4. **실시간 캔들 차트**: `react-native-echarts`. 실시간 틱으로 마지막 캔들 갱신. 추천 지지/저항선(점선), 내 진입가(실선) 오버레이.
5. **코칭 팝업**(조건부): 룰 엔진 넛지 메시지.
6. **내 포지션 카드**: 평가손익/수익률 틱 카운팅(up 빨강/down 파랑), `[즉시 전액 청산]`.
7. **주문 패널**: 비중 칩(25/50/100), 배율 칩(1x/2x/5x🔒 — 미해금 시 아카데미 연결), 대형 `🔴 BUY` / `🔵 SELL`.
- **로그인 게이팅(D5/D6)**: 비로그인 상태로 게임 탭 진입 시 차트·심리 등 "구경"은 가능하되, **BUY/SELL·청산 등 자본이 바뀌는 동작을 누르는 순간 간편로그인 바텀시트**를 띄운다. (차트까지 가릴지 여부는 구현 시 UX 확인 — 기본은 구경 허용)

#### 게임 바텀시트
- **🏆 랭킹**: Top 100 + 명예의 전당 탭.
- **🤝 지인리그**: 리그 생성 / 초대코드 참가 / 지인 랭킹.
- **🎯 퀘스트**: 일일/시즌 퀘스트 목록·보상.
- **🧩 야간 차트퀴즈**: 장 마감 후 플로팅 배너로 진입, 가려진 차트 + 10초 타이머 + 📈/📉 + 해설.

### 4.4 👤 내정보 (`(tabs)/profile.tsx`) — 재구성 (플레이어 마이페이지)
- **로그인 시**: 프로필 헤더(닉네임·등급) → `🏆 내 순위 요약` 카드 → 리스트 행: `🔥 Streak`, `🧬 Trading MBTI`, `🎓 아카데미(5x 해금 진행도)`, `📜 지난 시즌 기록`, `⚙️ 설정`, `🚪 로그아웃`.
- **비로그인 시**: "간편로그인하고 시작하기" 중심 + 설정 일부.
- MBTI/시즌기록 등 상세는 하위 화면 또는 바텀시트(구현 시 택1, 기본 = 하위 스택 화면).

## 5. 로그인/인증 플로우 (D5/D6)

- **상태**: `비로그인(게스트 둘러보기)` ↔ `로그인(간편로그인)`. 토큰/핸들러는 기존 `mobile/src/features/auth` + `lib/api/auth-token.ts` 재사용(저장소 `expo-secure-store`).
- **게이팅 지점**: ① 게임 BUY/SELL/청산 ② 블로그 댓글·글쓰기 ③ 내정보의 '나' 기능. 모두 **401/비로그인 → 간편로그인 바텀시트** 단일 흐름으로 통일.
- **간편로그인 바텀시트**: 제공자 버튼(O2) → 소셜 토큰 → 백엔드 `POST /api/v1/auth/social` 검증 → 앱 토큰 저장 → 원래 동작 재개.
- 기존 닉네임 게스트 로그인(`POST /auth/guest`)은 UI에서 제거하거나 "비로그인 둘러보기"로 의미 축소(구현 단계 정리).

## 6. 공통 컴포넌트 & 디자인 적용

디자인 언어(SSOT) = `docs/mobile_design_language.md`. 신규 공통 컴포넌트는 **`mobile/src/ui/`** 에 두고 재사용:
- `Button`(풀폭 CTA/보조), `Chip`(비중·배율·보드), `Card`, `ListRow`(제목+값+`›`), `BottomSheet`(그랩바·상단 라운드·딤), `ListState`(로딩/빈/에러), `AmountText`(±부호+up/down색+카운팅).
- 토큰 변경 반영: `mobile/unistyles.ts` light/dark에 `primary=#3182f6`, `up=#f04452`, `primarySoft` 신설(디자인 문서 2장).

## 7. 기존 기능 보존 (Regression)

- 홈/블로그/상세/댓글/인증 토큰 흐름의 **API 계약은 유지**. 변경은 네비게이션 등록(탭 제거/추가)과 화면 내부 구성·스타일에 한정.
- 탭 제거(screener/watchlist)는 라우트/파일 삭제 + 탭 등록 해제만. 다른 화면에서 해당 탭으로의 딥링크가 없는지 확인.
- 디자인 토큰 변경(primary 색 등)은 전역 영향 → 기존 화면도 함께 토스 토큰으로 수렴(의도된 변경).

## 8. 단계 분할(구현 순서 제안, YAGNI)

1. **디자인 토큰 + `src/ui` 공통 컴포넌트** (디자인 언어 반영) — 이후 모든 화면의 토대.
2. **탭 재편**: screener/watchlist 제거, game 탭 추가(스켈레톤), 순서 홈·블로그·게임·내정보.
3. **간편로그인 바텀시트 + 게이팅 흐름**(소셜 1종부터).
4. **내정보 마이페이지 재구성**(게임 데이터는 목/실제 API 연동 여부에 따라 단계적).
5. **게임 플레이 화면**(정적 → 실시간 WS 연동은 백엔드 Phase 3 준비 후). 바텀시트들은 화면 뒤에 점진 추가.
6. 홈 내 순위 배너(O1) 연결.

> 게임 플레이 화면의 실시간·주문은 백엔드 트레이딩 게임 Phase 1~5에 의존. 화면 구조는 먼저 세우고, 데이터는 준비되는 대로 연결한다.

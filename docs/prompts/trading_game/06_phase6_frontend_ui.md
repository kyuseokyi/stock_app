## 2. 주요 구현 기능 및 상태 관리

### 1) 실시간 캔들 차트 & 오버레이 (`TradingChart.tsx`)
- **라이브러리**: `lightweight-charts` 또는 모바일의 경우 `react-native-echarts` 활용
- **실시간 틱 반영**: WebSocket (`/ws/game/stream`)을 통해 수신되는 실시간 틱을 현재 진행 중인 마지막 캔들의 종가/고가/저가로 즉시 갱신
- **추천 지지선/저항선 오버레이**:
  - 관리자 코치 API에서 받아온 `support_price`, `resistance_price`를 차트 위 점선(보라색/주황색) Price Line으로 표시
- **진입가 라인 표시**: 포지션 진입 시 내 체결단가를 차트 위에 실선 라벨로 표시

### 2) 원클릭 주문 및 포지션 패널 (`OrderPanel.tsx`, `ActivePositionCard.tsx`)
- **원터치 비중 칩**: `25%`, `50%`, `100%(전액)` 클릭 시 즉시 선택
- **배율 선택 칩**: `1x`, `2x`, `5x` (5배율은 미해금 시 자물쇠 🔒 아이콘 표시 및 클릭 시 아카데미 퀴즈 모달 연결)
- **대형 원터치 버튼 2개**:
  - `[🔴 BUY (상승)]` (한국 증시 컬러: 상승 빨강)
  - `[🔵 SELL (하락)]` (한국 증시 컬러: 하락 파랑)
  - 클릭 즉시 `POST /api/game/orders` 호출 (원클릭 체결)
- **실시간 포지션 카드**:
  - 보유 포지션이 있을 때 실시간 평가손익금(예: `+₩180,000`) 및 수익률(예: `+14.4%`)이 틱마다 초록/빨강 카운팅 애니메이션
  - `[즉시 전액 청산하기]` 버튼: 누르면 즉시 시장가 청산 API 호출

### 3) 소셜 & 에듀테인먼트 모달 컴포넌트
- **실시간 랭킹 모달 (`LeaderboardModal.tsx`)**: Top 100 랭커 목록 및 명예의 전당 탭
- **지인 리그 모달 (`PrivateLeagueModal.tsx`)**: 리그 생성, 초대코드 입력 참가, 지인들만의 랭킹표
- **야간 10초 차트 퀴즈 모달 (`ChartQuizModal.tsx`)**:
  - 장 마감 후 또는 야간에 진입 가능한 퀴즈 화면
  - 가려진 캔들 차트 표시 후 10초 타이머 카운트다운
  - [오를까? 📈] [내릴까? 📉] 버튼 선택 후 즉시 정답 및 교육 해설 모달 표시
- **Trading MBTI 리포트 카드 모달 (`MbtiReportModal.tsx`)**:
  - 시즌 마감 시 또는 프로필에서 확인할 수 있는 나의 트레이딩 성향 공유 카드 (SNS 공유용 레이아웃)

## 3. 작업 순서 (Step by Step)

1. **상태 관리 및 WebSocket 훅 구현 (`web_client/src/stores/useTradingGameStore.ts`)**:
   - 실시간 틱 데이터, 현재 포지션 PnL, 유저 계좌 잔고, 시장 심리 비율을 관리하는 Zustand 스토어 작성
   - 백엔드 WebSocket 연결 및 재연결 관리 훅 (`useGameWebSocket.ts`)
2. **트레이딩 페이지 및 컴포넌트 구현 (`web_client/src/pages/TradingGamePage.tsx`)**:
   - 상단 헤더 및 코치 가이드 롤링 배너
   - 실시간 캔들 차트 컴포넌트
   - 원클릭 주문 패널 및 포지션 카드 컴포넌트
3. **모달 컴포넌트 구현**:
   - 랭킹/지인리그 모달, 야간 차트 퀴즈 모달, 퀘스트/Streak 모달
4. **모바일(`mobile/`) 대응 컴포넌트 작성**:
   - React Native 스크린 (`mobile/src/screens/TradingGameScreen.tsx`) 구현 및 동일 API/WS 연동
5. **검증 및 빌드 테스트**:
   - 웹: `cd web_client && npm run build`
   - 모바일: `cd mobile && npx expo lint` (또는 타입체크)

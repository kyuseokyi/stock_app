# 로고 시안 기록

> **결정(2026-11-10): D — 웃는 수익률** (바닥 U 위로 오늘의 점 하나). 최종 키트는 상위 폴더 [`../`](../README.md).
> 여기 있는 것은 고르는 과정에서 만든 시안이다. 나중에 다시 비교해 볼 수 있게 지우지 않고 남겨 둔다.
> `board.html` 은 그림이 파일 안에 들어 있어 브라우저로 바로 열면 된다.

| 차수 | 폴더 | 무엇 | 결과 |
|---|---|---|---|
| 0 | `0-stockapp/` | "StockApp"·오닐 추세추종 가정으로 만든 첫 시안(캔들·돌파 등) | 앱 이름·성격을 잘못 가정 — 폐기. 여기서 나온 U+점 도형이 나중에 D 가 됨 |
| 1 | `1-funnotedaily/` | funnotedaily 이름으로 만든 A 책갈피 · B 해돋이 · C 웃음 | B 는 모자처럼 읽힘 |
| 2 | `2-funnote/` | 앱 이름 FunNote 기준 A F 노트 · B N 한 획 · C 웃는 노트 · **D 웃는 수익률(현재)** | B 는 "Ni" 로 읽힘. 이 차수의 D 를 최종 선택 |
| 3 | `3-ac-mix/` | A·C 와 둘을 섞은 E1(F 노트 카드)·E2(웃는 F 노트) 색 비교, 한 색 테스트, 발표 보드 12장 | E2 는 작게 보면 "FJ" 로 읽힘 |

## 파일

- `concepts.png` / `compare.png`: 한 장 비교(큰 기호, 로고, 64·32·16px 실제 크기)
- `mono.png`: 한 색 테스트(3차 E1·E2)
- `board.html`, `slides/`: 발표 보드(앱 아이콘·웹·탭·카드 목업). 3차 목업 속 주소는 `funnotedaily.com`
- `*-symbol*.svg`, `*-lockup*.svg`: 시안 원본. 시안이라 작은 크기 전용판·광학 보정은 하지 않았다

## 다른 시안으로 바꾸고 싶어지면

시안 SVG 를 기준으로 [`../source/make_kit.py`](../source/make_kit.py) 의 기호 도형(`U`, `DOT`, 작은 판 `U_S`, `DOT_S`)을 바꿔 키트를 다시 만든다.
E1 은 16px 에서 F 가 흐려지므로 작은 크기 전용판을 따로 그려야 한다.

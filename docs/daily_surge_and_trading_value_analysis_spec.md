# 날짜별 종가 기준 급등주(+10~+30%) · 급락주(-10~-30%) · 거래대금 상위 & 장전·장중 뉴스·테마·대장주 분석기 기획 및 구현 명세서

> ⚠️ **구현 설계는 [`superpowers/specs/2026-11-26-daily-surge-theme-analyzer-design.md`](superpowers/specs/2026-11-26-daily-surge-theme-analyzer-design.md) 가 우선**한다 — 네이버 뉴스 약관(저장·재배열·가공 금지) 때문에 뉴스는 저장하지 않고 화면에서 바로 보기, 이유는 DART 공시·관리자 메모, 테마는 키움 기준(2026-11-26).

> **작성일**: 2026-11-26 (개정: 뉴스 원문 링크, 장 시작 전 뉴스 기반 선행 급등/급락 이유 분리, 급락주 -10%~-30% 추가)  
> **상태**: 확정 (클로드 코드가 바로 구현 가능한 상세 기획 및 단계별 구현 계획)  
> **목적**: 매일 장 마감 후(종가 기준) **급등주(+10% ~ +30%)**, **급락주(-10% ~ -30%)**, **거래대금 상위 종목(Top 50)**을 **날짜별로 분류·저장**하고, 각 종목의 **종가·거래량·전일대비 가격·등락률·거래대금**과 함께 **① 장 시작 전(~09:00) 선행 뉴스/공시 vs ② 장중·장후(09:00~) 뉴스 기반 급등/급락 사유 및 뉴스 기사 원문 링크**, **핵심 테마·이슈 키워드(예: `보안`, `한한령 해제`, `유상증자`, `실적쇼크`)**, **동일 테마 소속 종목 목록 및 당일 대장주**를 한눈에 비교·정렬할 수 있는 분석 시스템을 구축한다.  
> **노출 정책 (시세 라이선스 & Zero Deletion 준수)**: 관리자 웹(`admin_web` > `시장 데이터` > `🔥 급등락·거래대금 분석 (/market/daily-surge)`)에서는 **상시 100% 전체 노출**하며, 일반 사용자 웹/앱에서는 시세 공개 스위치(`marketData` 또는 시세 열람 권한 회원)가 켜졌을 때만 노출한다.

## 1. 핵심 요구사항 및 기획 포인트

### 1.1 날짜별 분류 및 4대 대상 종목군 (장 마감 종가 기준)
매일 장 마감 후(20:30 일봉 및 시장 그룹 파이프라인 직후) ClickHouse `daily_prices` 및 `market_stock_daily` 확정 종가를 기준으로 해당 거래일의 핵심 종목을 추출합니다.

1. **🔥 급등주 (`+10.0%` ~ `+30.0%` 상한가 구간)**:
   * 당일 등락률(`chg_1d`)이 **`+10.0%` 이상 ~ `+30.0%`(상한가)**인 보통주(ETF·SPAC·우선주 제외).
   * 기본 정렬: **`+30% → +10%` 내림차순**.
   * 세부 구간 필터 칩:
     * `[전체 (+10%~+30%)]`
     * `[상한가·초급등 (+25%~+30%)]`
     * `[강세 급등 (+15%~+25%)]`
     * `[탄력 급등 (+10%~+15%)]`
2. **💧 급락주 (`-10.0%` ~ `-30.0%` 하한가 구간)**:
   * 당일 등락률(`chg_1d`)이 **`-10.0%` 이하 ~ `-30.0%`(하한가)**인 보통주.
   * 기본 정렬: **`-30% → -10%` 급락폭 큰 순서(오름차순)** 또는 `-10% → -30%` 토글 가능.
   * 세부 구간 필터 칩:
     * `[전체 (-10%~-30%)]`
     * `[하한가·초급락 (-25%~-30%)]`
     * `[심한 급락 (-15%~-25%)]`
     * `[조정 급락 (-10%~-15%)]`
   * 급락주 역시 급등주와 100% 동일한 컬럼(종가, 전일대비 가격, 등락률, 거래량, 거래대금, **급락 이유 & 뉴스 기사 링크**, 테마/악재 키워드 예: `#유상증자`, `#CB전환`, `#실적쇼크`, `#임상실패`, 동일 테마 동반 하락 여부 및 테마 내 대장주 비교)을 제공합니다.
3. **💰 거래대금 상위 (Top 50 & 기준 금액 필터)**:
   * 등락률과 무관하게 당일 거래대금(`value = 종가 × 거래량`) 상위 50개 종목.
4. **🎯 교집합 모드 (`[급등+거래대금]` / `[급락+거래대금]`)**:
   * 등락률 `±10% ~ ±30%`이면서 동시에 거래대금 상위 50위 이내(또는 300억 이상)인 **대량 수급 동반 급등/급락주**만 필터링.
5. **📅 날짜별 아카이빙 & 장전 프리마켓(08:40) 선행 레이더**:
   * 과거 거래일별로 스냅샷과 장전/장중 뉴스·테마 원인이 영구 보존되어 날짜 선택기로 언제든 복기할 수 있습니다.

### 1.2 🌅 장 시작 전(Pre-Market) 뉴스 vs ☀️ 장중(In-Market) 뉴스 시점 분리 및 원문 링크 제공

사용자 요청 사항인 **"뉴스 기사 링크도 같이 보고 싶고, 가능하면 장 시작 전의 뉴스 기사에서 급등(또는 급락) 이유를 확인하고 싶다"**를 충족하기 위해 뉴스 수집 및 시각 분류를 다음과 같이 **2-Track 시점 분리 구조**로 설계합니다:

#### ① 뉴스 발행 시각(`pubDate`) 기반 [🌅 장전 뉴스] vs [☀️ 장중·장후 뉴스] 자동 태깅
해당 거래일(`T일`)의 급등/급락 원인이 **장 시작 전에 이미 나온 재료(선행 재료)**인지, 아니면 **장중에 돌발적으로 나온 재료(또는 오른 뒤 사후에 붙은 특징주 기사)**인지 구분하는 것이 매매 복기에서 가장 중요합니다!

* **🌅 장 시작 전 뉴스 (`PRE_MARKET`)**:
  * **시간 범위**: **`전일(T-1일) 15:30 장 마감 직후 ~ 당일(T일) 09:00 정규장 시작 전`** 사이에 발행된 뉴스 및 야간/장전 DART 공시.
  * **의미**: 장이 열리기 전에 이미 보도된 `[단독]`, `수주/계약 공시`, `미국장 밤사이 이슈`, `유상증자/CB 발행(장후 공시)`, `정부 정책 발표` 등 **시초가 갭상승/갭하락이나 당일 급등락을 유발한 ‘진짜 선행 재료’**입니다.
  * 화면에 **`[🌅 장전 07:42]`** 와 같이 골드/인디고 강조 배지로 최상단에 우선 노출합니다.
* **☀️ 장중·장후 뉴스 (`INTRADAY` / `POST_MARKET`)**:
  * **시간 범위**: **`당일(T일) 09:00 이후 ~ 20:30`** 사이에 발행된 뉴스 및 공시.
  * **의미**: 장중 속보나 주가가 급등/급락한 뒤 기자가 사후적으로 작성한 `[특징주]` 해설 기사입니다.
  * 화면에 **`[☀️ 장중 10:15]`**, **`[🌙 장후 16:05]`** 배지로 구분해 표시합니다.

#### ② 장 시작 전(08:40 KST) ‘오늘의 장전 뉴스 포착 후보’ 선행 배치 지원 (보너스 기능)
* 장 마감 후(20:30) 확정 종가 분석뿐만 아니라, **매일 아침 장 시작 전 `08:40 KST`**(또는 관리자 `[🌅 장전 뉴스 스캔]` 버튼 클릭 시)에 `전일 15:30 ~ 당일 08:40` 사이의 주요 특징주/단독/공시 뉴스를 미리 스캔하여 **"오늘 장전 호재/악재 뉴스 포착 종목"** 탭에서 미리 기사와 링크를 확인할 수 있게 지원합니다.
* 이어서 장 마감 후(20:30) 실제 `+10~+30%` 급등 또는 `-10~-30%` 급락한 종목을 집계할 때, 아침에 나왔던 **장전 뉴스(`PRE_MARKET`)**와 장중 뉴스(`INTRADAY`)를 모두 매칭해 저장합니다.

#### ③ 클릭 가능한 뉴스 기사 원문 링크 (`news_items`)
* 모든 종목 행과 우측 상세 패널에는 요약된 급등/급락 이유뿐만 아니라 **실제 뉴스 기사 목록(최대 5~8건: 장전 뉴스 우선 최대 4건 + 장중 특징주 뉴스 최대 4건)**이 함께 저장·표시됩니다.
* 각 뉴스 항목 구성:
  * `time_slot`: `"PRE_MARKET"` (`🌅 장전`) | `"INTRADAY"` (`☀️ 장중`) | `"POST_MARKET"` (`🌙 장후`)
  * `published_at`: 발행 시각 (예: `"08:15"`, `"전일 17:40"`, `"11:20"`)
  * `title`: 뉴스 기사 제목 (예: `"[단독] 정부, 국가망 클라우드 보안 예산 2배 확대 추진"`)
  * `url`: **클릭 시 새 탭(`target="_blank"`)으로 즉시 열리는 원문 기사 링크 (`originallink` 또는 네이버 뉴스/공시 링크)**
  * `source`: 언론사명 또는 `DART 전자공시`

### 1.4 다중 정렬(Sorting) 및 필터 기능
목록 상단 컬럼 헤더를 클릭하거나 정렬 칩을 통해 즉시 재정렬할 수 있습니다:
1. **등락률 순**:
   * 급등주 탭 기본값: **`+30% → +10%` 내림차순**
   * 급락주 탭 기본값: **`-30% → -10%` 오름차순(하락폭 큰 순서)** (클릭 시 `-10% → -30%` 전환)
2. **거래대금 순** (`내림차순` / `오름차순`): 큰 자금이 터진 주도주부터 정렬
3. **거래량 순** / **전일 대비 거래량 배수(%) 순**
4. **전일대비 가격 변동폭 순** / **종가 순**
5. **🌅 장전 뉴스 보유 우선 정렬**: 장 시작 전(`~09:00`)에 이미 선행 뉴스/공시가 있었던 종목만 위로 모아보기 필터/정렬
6. **테마 그룹별 묶어보기**: 같은 테마 종목끼리 그룹화하여 **대장주(👑) → 2등주 → 3등주** 순으로 정렬

## 3. 백엔드 데이터베이스 및 아키텍처 설계

### 3.1 PostgreSQL 테이블 설계 (`daily_surge_analyses`)
급등주(`+10% ~ +30%`), 급락주(`-10% ~ -30%`), 거래대금 상위(Top 50) 종목과 **장전(`pre_market_news`) / 장중(`intraday_news`) 뉴스 원문 링크 및 이유**를 저장합니다.

```sql
CREATE TABLE daily_surge_analyses (
    id SERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,                      -- 거래일 (YYYY-MM-DD)
    ticker VARCHAR(20) NOT NULL,                   -- 종목코드
    stock_name VARCHAR(100) NOT NULL,
    market VARCHAR(20) NOT NULL,                   -- KOSPI | KOSDAQ
    close_price FLOAT NOT NULL,                    -- 당일 종가
    prev_close FLOAT NOT NULL,                     -- 전일 종가
    change_price FLOAT NOT NULL,                   -- 전일대비 가격 (close - prev_close, 급락주는 음수)
    change_rate FLOAT NOT NULL,                    -- 등락률 (%, 급등주 +10~+30 / 급락주 -10~-30)
    volume BIGINT NOT NULL,                        -- 당일 거래량
    volume_ratio FLOAT NULL,                       -- 전일 거래량 대비 비율 (%)
    trading_value FLOAT NOT NULL,                  -- 당일 거래대금 (원)
    is_surge BOOLEAN NOT NULL DEFAULT FALSE,       -- 급등주 (+10.0% ~ +30.5%) 여부
    is_plunge BOOLEAN NOT NULL DEFAULT FALSE,      -- 급락주 (-10.0% ~ -30.5%) 여부
    is_top_value BOOLEAN NOT NULL DEFAULT FALSE,   -- 거래대금 상위 (Top 50) 여부
    value_rank INTEGER NULL,                       -- 당일 전체 거래대금 순위
    surge_rank INTEGER NULL,                       -- 당일 상승률 순위
    plunge_rank INTEGER NULL,                      -- 당일 하락률 순위
    primary_theme_id INTEGER NULL,                 -- 당일 대표 테마 ID
    primary_theme_name VARCHAR(100) NULL,          -- 예: '정보보안', '화장품'
    theme_keywords JSONB NOT NULL DEFAULT '[]',    -- 추출된 키워드 배열 (예: ["보안", "한한령", "유상증자"])
    pre_market_reason VARCHAR(300) NULL,           -- 🌅 장 시작 전 뉴스/공시 기반 선행 이유 요약
    intraday_reason VARCHAR(300) NULL,             -- ☀️ 장중 특징주 뉴스/공시 기반 이유 요약
    reason_summary VARCHAR(300) NULL,              -- 통합 1줄 핵심 이유 (장전 우선, 없으면 장중)
    has_pre_market_news BOOLEAN NOT NULL DEFAULT FALSE, -- 장전(~09:00) 뉴스/공시 존재 여부 (필터링용)
    news_items JSONB NOT NULL DEFAULT '[]',        -- [{title, url, source, published_at, time_slot: 'PRE_MARKET'|'INTRADAY'|'POST_MARKET'}]
    leader_ticker VARCHAR(20) NULL,                -- 동일 테마 내 당일 대장주 종목코드
    leader_name VARCHAR(100) NULL,                 -- 동일 테마 내 당일 대장주 종목명
    leader_change_rate FLOAT NULL,                 -- 대장주 당일 등락률
    is_theme_leader BOOLEAN NOT NULL DEFAULT FALSE,-- 본 종목이 해당 테마의 당일 대장주인지 여부
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_daily_surge_date_ticker UNIQUE (trade_date, ticker)
);
CREATE INDEX idx_daily_surge_trade_date ON daily_surge_analyses (trade_date);
```

### 3.2 장 시작 전 뉴스 vs 장중 뉴스 분류 및 검색 로직 (`backend/apps/collector/daily_surge.py`)

1. **시간대 판별 기준 (`classify_news_time_slot(pub_dt, trade_date, prev_trade_date)`)**:
   * **유효 수집 창**: `직전 거래일(prev_trade_date) 15:30 KST` ~ `당일(trade_date) 23:59 KST`
   * **`PRE_MARKET` (🌅 장전 뉴스)**:
     * `prev_trade_date 15:30 KST <= pub_dt < trade_date 09:00 KST`
     * 전날 장 마감 후 발표된 야간 공시/기사와 당일 아침 09:00 개장 전에 나온 조간·단독·프리마켓 기사를 정확히 포착합니다.
   * **`INTRADAY` (☀️ 장중 뉴스)**:
     * `trade_date 09:00 KST <= pub_dt <= trade_date 15:30 KST`
   * **`POST_MARKET` (🌙 장마감 후 복기 뉴스)**:
     * `trade_date 15:30 KST < pub_dt <= trade_date 23:59 KST`

2. **뉴스 및 공시 멀티 쿼리 수집**:
   * **쿼리 1 (종목 특징주/이유 검색)**:
     * 급등주/거래대금 상위: `f"{stock_name} 특징주"` 및 `f"{stock_name}"` (최신순/정확도순 결합 후 해당 날짜 범위 필터링)
     * 급락주: `f"{stock_name} 특징주"` 및 `f"{stock_name} 급락"` 또는 **OpenDART 당일/전일 공시**(유상증자, 전환사채 전환청구, 감사보고서, 영업손실 등 악재 공시는 뉴스보다 DART에 먼저 나옴)
   * **쿼리 2 (테마 공통 이슈 키워드 추출)**:
     * 같은 테마에서 2개 이상 동반 급등/급락한 경우(예: `안랩` + `지니언스`, 또는 `한국화장품` + `토니모리`), 해당 종목들의 뉴스 제목에서 불용어(`특징주`, `강세`, `급등`, `상승`, `주가`, 종목명 자체)를 제외한 **빈도 상위 핵심 명사 키워드(예: `#보안`, `#AI커닝`, `#한한령`, `#비자면제`, `#유상증자`)**를 자동 추출해 `theme_keywords`에 저장합니다.
   * **원문 링크 보존 (`url`)**:
     * 네이버 뉴스 검색 API 응답의 `originallink`(언론사 원문 URL, 비어 있으면 `link` 네이버 뉴스 URL)와 DART 공시 뷰어 URL(`https://dart.fss.or.kr/dsaf001/main.do?rcpNo=...`)을 `news_items` 배열에 그대로 저장하여 프론트엔드에서 클릭 한 번으로 원문 기사를 열 수 있게 합니다.

## 4. 클로드코드(Claude Code) 단계별 구현 계획

클로드 코드에서 작업할 때 아래 5단계 순서대로 진행합니다.

### Step 1: DB 모델(`DailySurgeAnalysis`) 및 마이그레이션 생성
* `backend/shared/market_models.py`에 `DailySurgeAnalysis` 모델 추가 (`is_surge`, `is_plunge`, `is_top_value`, `pre_market_reason`, `intraday_reason`, `has_pre_market_news`, `news_items`, `theme_keywords`, `leader_ticker` 포함).
* Alembic 마이그레이션 생성 (`daily_surge_analyses` 테이블).

### Step 2: 종가 기반 급등(+10~+30%)·급락(-10~-30%)·거래대금 상위 추출 및 장전/장중 뉴스·테마 대장주 분석기 구현
* `backend/apps/collector/daily_surge.py` (신규):
  1. ClickHouse `daily_prices FINAL` 및 `market_stock_daily FINAL`에서 지정 거래일(`trade_date`)과 직전 거래일(`prev_trade_date`) 데이터를 읽어 `close_price`, `prev_close`, `change_price`, `change_rate`, `volume`, `volume_ratio`, `trading_value` 계산.
  2. **급등주(`+10.0% <= change_rate <= +30.5%`)**, **급락주(`-30.5% <= change_rate <= -10.0%`)**, **거래대금 상위 Top 50** 추출.
  3. PG `themes` × `theme_stocks`와 조인해 대표 테마 선정 및 테마 내 당일 등락률/거래대금 1위 **대장주(👑)** 판별.
  4. 네이버 뉴스 검색 클라이언트(`naver_news.py`) + 공개 경제 RSS + OpenDART 공시 클라이언트를 호출하여 기사를 수집하고, 발행 시각(`pubDate`)을 파싱해 **`PRE_MARKET`(직전 거래일 15:30 ~ 당일 09:00)** 과 **`INTRADAY`(당일 09:00 이후)** 로 분류하여 **원문 링크(`url`)**와 함께 저장.
  5. 뉴스 헤드라인에서 장전 이유(`pre_market_reason`), 장중 이유(`intraday_reason`), 테마 키워드(`theme_keywords`: 예 `#보안`, `#한한령`, `#유상증자`) 추출.
* `backend/apps/collector/tasks.py`:
  * 매일 20:30 파이프라인 끝에 `collector.analyze_daily_surge_and_value` 자동 연결.

### Step 3: FastAPI 조회·정렬·필터 REST API 구현
* `backend/apps/stock_api/services/daily_surge_query.py` & `backend/apps/stock_api/routers/daily_surge.py` (신규) 및 `backend/apps/stock_api/main.py` 라우터 등록.
* `mode` (`surge` | `plunge` | `value` | `surge_value` | `plunge_value`), `band` (`10_15` | `15_25` | `25_30`), `pre_market_only`, `sort` (`change_rate` | `trading_value` | `volume` | `change_price` | `pre_market` | `theme`) 지원.

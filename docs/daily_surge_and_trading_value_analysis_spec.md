# 날짜별 종가 기준 급등주(10~30%) & 거래대금 상위 · 테마·뉴스·대장주 분석기 기획 및 구현 명세서

> **작성일**: 2026-11-26  
> **상태**: 확정 (클로드 코드가 바로 구현 가능한 상세 기획 및 단계별 구현 계획)  
> **목적**: 매일 장 마감 후(종가 기준) **거래대금 상위 종목** 및 **급등주(등락률 +10% ~ +30% 상한가)**를 **날짜별로 분류·저장**하고, 각 종목의 **종가·거래량·전일대비 가격·등락률·거래대금**과 함께 **뉴스 기반 급등/거래대금 유입 사유**, **핵심 테마·이슈 키워드(예: `보안`, `한한령 해제`, `HBM`)**, **동일 테마 소속 종목 목록 및 당일 대장주**를 한눈에 비교·정렬할 수 있는 분석 시스템을 구축한다.  
> **노출 정책 (시세 라이선스 & Zero Deletion 준수)**: 관리자 웹(`admin_web` > `시장 데이터` > `🔥 급등·거래대금 분석 (/market/daily-surge)`)에서는 **상시 100% 전체 노출**하며, 일반 사용자 웹/앱에서는 시세 공개 스위치(`marketData` 또는 시세 열람 권한 회원)가 켜졌을 때만 노출한다.

## 1. 핵심 요구사항 및 기획 포인트

### 1.1 날짜별 분류 및 대상 종목 선정 기준 (장 마감 종가 기준)
매일 장 마감 후(20:30 일봉 및 시장 그룹 파이프라인 직후) ClickHouse `daily_prices` 및 `market_stock_daily` 확정 종가를 기준으로 해당 거래일의 핵심 종목을 추출합니다.
1. **🔥 급등주 (+10% ~ +30% 구간 필터)**:
   * 당일 등락률(`chg_1d`)이 **`+10.0%` 이상 ~ `+30.0%`(상한가) 이하**인 보통주(ETF·SPAC·우선주 제외).
   * 화면에서 구간 필터 칩 제공:
     * `[전체 (+10%~+30%)]`
     * `[상한가·초급등 (+25%~+30%)]`
     * `[강세 급등 (+15%~+25%)]`
     * `[탄력 급등 (+10%~+15%)]`
2. **💰 거래대금 상위 (Top 50 & 기준 금액 필터)**:
   * 당일 거래대금(`value = 종가 × 거래량`) 상위 50개 종목 (또는 `500억 이상` / `1,000억 이상` 필터).
3. **🎯 교집합 모드 (`[급등 + 거래대금 상위 동시 충족]`)**:
   * 등락률 `+10% ~ +30%`이면서 동시에 거래대금도 터진(예: 거래대금 상위 50위 이내 또는 300억 이상) **‘진짜 수급 주도 급등주’**만 모아보는 필터.
4. **📅 날짜별 아카이빙 및 캘린더 탐색**:
   * 단순 당일 조회만 되는 것이 아니라, **과거 거래일별로 스냅샷과 뉴스·테마 원인이 영구 보존**됩니다.
   * 상단 날짜 선택기(`[◀ 이전 거래일]` `2026-11-26 (목)` `[다음 거래일 ▶]` + 최근 30거래일 빠른 날짜 칩)로 날짜를 바꾸면 그날의 급등주·거래대금 상위 목록과 당시 상승 이유·테마 대장주를 그대로 복기할 수 있습니다.

### 1.3 테마 키워드 · 동반 테마주 · 대장주 판별 로직 상세

사용자가 요청하신 **"안랩·지니언스라면 키워드는 `보안`, 화장품주라면 `한한령` 같은 키워드와 같은 테마주 목록 및 대장주 찾기"**를 정확히 구현하기 위해 **2단계 하이브리드 매핑**을 사용합니다:

1. **1단계 — DB 테마 마스터 기반 정밀 매핑 (환각 0%)**:
   * 종목이 속한 모든 활성 테마(`themes` × `theme_stocks`, KIS/키움 테마 + 관리자 보정 테마)를 조회합니다.
   * 한 종목이 여러 테마(예: 안랩이 `정보보안`, `안철수`, `클라우드` 3개 테마)에 속해 있을 경우, **해당 거래일에 구성 종목들의 평균 등락률(`chg_1d`)이 가장 높았던 테마**를 **‘오늘의 대표 주도 테마’**로 자동 선정합니다.
2. **2단계 — 뉴스 헤드라인 기반 ‘실시간 재료 키워드’ 추출**:
   * 정적 테마명(`화장품`, `정보보안`)만으로는 그날 왜 올랐는지(`한한령 해제`, `미국 수출 역대 최고`, `양자암호 국책과제`)를 알 수 없습니다.
   * 해당 종목과 동반 상승한 같은 테마 종목들의 당일 뉴스 제목에서 공통으로 반복 등장하는 명사구/핵심 키워드(예: `#한한령`, `#중국단체관광`, `#사이버보안`, `#HBM4`)를 추출하여 **테마 키워드 뱃지**로 함께 태깅합니다.
   * *(법무/약관 안전장치)*: [`docs/naver-search-api-terms-issue.md`](naver-search-api-terms-issue.md)의 네이버 검색 API 약관(2026-09-07 개정)을 준수하기 위해, 공개 사용자 화면용으로는 연합뉴스·이데일리 증권 공식 RSS(`yna.co.kr/rss/economy.xml`, `rss.edaily.co.kr/stock_news.xml`) + DART 공시를 기본 분석 소스로 사용하고, 관리자 전용 본인이용 화면(`admin_web`)에서는 네이버 뉴스 검색 결과 원문 링크 목록을 가공 없이 함께 조회할 수 있도록 분리합니다.
3. **3단계 — 동일 테마 종목 목록 및 ‘당일 대장주(👑)’ 자동 판별**:
   * 대표 테마에 속한 구성 종목 전체의 **해당 날짜 종가·등락률·거래대금**을 가져와 내림차순으로 정렬합니다.
   * **대장주(👑 Leader) 판별 공식**:
     * 1순위: 해당 날짜에 **상한가(+29.5% 이상)**에 가장 먼저/강하게 도달하고 거래대금이 가장 큰 종목.
     * 2순위: 해당 테마 내에서 **당일 등락률(`chg_1d`) 1위**(단, 거래대금이 최소 기준 이상인 종목)를 **등락률 대장주(👑)**로, **당일 거래대금(`value`) 1위**를 **수급 대장주(💰)**로 표시합니다.
   * 덕분에 내가 선택한 종목이 오늘 **테마 내 1등 대장주인지, 아니면 대장주(예: 안랩)를 따라 오른 2등·3등 후발주(예: 지니언스)인지** 즉시 판별할 수 있습니다!

### 1.4 다중 정렬(Sorting) 및 필터 기능
목록 상단 컬럼 헤더를 클릭하거나 정렬 드롭다운을 통해 즉시 재정렬할 수 있습니다:
* **지원하는 정렬 기준 (오름차순 / 내림차순 토글)**:
  1. **등락률 순 (기본값: `+30% → +10%` 내림차순)**
  2. **거래대금 순 (내림차순: 큰 돈이 몰린 순서)**
  3. **거래량 순 / 전일 대비 거래량 급증률(%) 순**
  4. **종가 / 전일대비 상승폭 순**
  5. **테마 그룹별 묶어보기 (같은 테마 종목끼리 묶어서 대장주 → 후발주 순 정렬)**

## 3. 백엔드 데이터베이스 및 아키텍처 설계

### 3.1 PostgreSQL 테이블 설계 (`daily_surge_snapshots`)
ClickHouse의 일봉(`daily_prices`)과 종목별 거래대금(`market_stock_daily`)은 이미 날짜별로 저장되어 있으므로, **날짜별 급등주/거래대금 상위 종목의 뉴스 사유·테마 키워드·대장주 매핑 결과**를 PostgreSQL에 캐싱·보관하는 테이블 1개를 추가합니다.

```sql
CREATE TABLE daily_surge_analyses (
    id SERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,                    -- 거래일 (YYYY-MM-DD)
    ticker VARCHAR(20) NOT NULL,                 -- 종목코드
    stock_name VARCHAR(100) NOT NULL,
    market VARCHAR(20) NOT NULL,                 -- KOSPI | KOSDAQ
    close_price FLOAT NOT NULL,                  -- 당일 종가
    prev_close FLOAT NOT NULL,                   -- 전일 종가
    change_price FLOAT NOT NULL,                 -- 전일대비 가격 (close - prev_close)
    change_rate FLOAT NOT NULL,                  -- 등락률 (%)
    volume BIGINT NOT NULL,                      -- 거래량
    trading_value FLOAT NOT NULL,                -- 거래대금 (원)
    is_surge BOOLEAN NOT NULL DEFAULT FALSE,     -- 등락률 10% ~ 30% 급등주 해당 여부
    is_top_value BOOLEAN NOT NULL DEFAULT FALSE, -- 당일 거래대금 상위(Top 50) 해당 여부
    value_rank INTEGER NULL,                     -- 당일 전체 거래대금 순위
    surge_rank INTEGER NULL,                     -- 당일 등락률 순위
    primary_theme_id INTEGER NULL,               -- 당일 대표 주도 테마 ID
    primary_theme_name VARCHAR(100) NULL,        -- 예: '정보보안', '화장품'
    theme_keywords JSONB NOT NULL DEFAULT '[]',  -- 추출된 핵심 키워드 배열 (예: ["보안", "AI보안", "클라우드"])
    reason_summary VARCHAR(300) NULL,            -- 급등 / 거래대금 상위 1줄 핵심 이유
    news_items JSONB NOT NULL DEFAULT '[]',      -- 관련 뉴스 제목·링크·언론사·시각 최대 5건
    leader_ticker VARCHAR(20) NULL,              -- 동일 테마 내 당일 대장주 종목코드
    leader_name VARCHAR(100) NULL,               -- 동일 테마 내 당일 대장주 종목명
    is_theme_leader BOOLEAN NOT NULL DEFAULT FALSE, -- 본 종목이 해당 테마의 당일 대장주인지 여부
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_daily_surge_date_ticker UNIQUE (trade_date, ticker)
);
CREATE INDEX idx_daily_surge_trade_date ON daily_surge_analyses (trade_date);
```

### 3.2 장 마감 후 자동 집계 파이프라인 (`backend/apps/collector/daily_surge.py`)
매일 저녁 **20:30 일일 파이프라인**(`collect_all_daily` → `compute_market_groups`)이 끝난 직후 `collector.analyze_daily_surge_and_value(as_of=None)` 태스크가 자동 실행됩니다:

1. **ClickHouse 종가 데이터 추출**:
   * 해당 기준일(`trade_date`)의 보통주 유니버스에서 직전 거래일 종가(`prev_close`)와 당일 종가(`close`), 거래량(`volume`), 거래대금(`value`)을 한 번에 조회합니다.
   * **급등주 조건**: `10.0 <= change_rate <= 30.5` (상한가 부동소수점 오차 감안 `30.5%`까지).
   * **거래대금 상위 조건**: 당일 `value` 내림차순 상위 50개 종목.
   * 두 집합의 합집합(일평균 약 60~80종목)을 분석 대상으로 선정합니다.
2. **테마·동반주·대장주 매핑**:
   * PostgreSQL `themes` × `theme_stocks`와 해당 거래일 `market_stock_daily`를 조인하여 각 종목의 소속 테마 중 당일 평균 등락률이 가장 높은 테마를 `primary_theme`으로 지정합니다.
   * 해당 테마 소속 종목 중 당일 등락률 1위(거래대금 50억 이상 우선)를 `leader_ticker`로 판별하고, 본 종목이 1위이면 `is_theme_leader = True`로 표시합니다.
3. **뉴스 검색 및 이유·키워드 추출**:
   * 대상 종목별로 당일 뉴스(공식 RSS + DART 공시 + 관리자용 네이버 뉴스 검색 `"{종목명} 특징주"`)를 조회합니다.
   * 뉴스 제목에서 핵심 이슈 키워드(예: `보안`, `한한령`, `수주`, `실적`)와 1줄 급등 사유를 추출하여 `daily_surge_analyses` 테이블에 Upsert합니다.
   * 과거 날짜를 처음 조회할 때도 온디맨드(On-demand)로 ClickHouse 과거 일봉에서 즉시 계산·생성할 수 있도록 폴백을 지원합니다.

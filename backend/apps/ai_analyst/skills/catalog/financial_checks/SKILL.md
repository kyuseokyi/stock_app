# 재무 점검·업종 비교 (국내 주식용)

> 출처: anthropics/financial-services (Apache-2.0) 의 재무 점검 흐름을 참고해 KIS 재무비율 수집값에 맞게 다시 씀(원문 복사 아님).

## 입력으로 받는 정량 팩트
- `peer_valuation`: 대상 종목 PER(종가 ÷ 연간 EPS)·PBR(종가 ÷ BPS)·ROE, 같은 업종(`sector_m`) 중앙값, 괴리율(%), 표본 수.
  EPS·BPS 가 0 이하인 종목은 해당 비율 중앙값에서 빠져 있다.
- `earnings_trend`: 최근 4개 분기 영업이익 증가율 나열과 가속 여부, 최근 매출·순이익 증가율, 부채비율.

## 점검 항목과 판정 기준
1. **밸류에이션**: PER·PBR 이 업종 중앙값보다 30% 이상 낮으면 "할인", 30% 이상 높으면 "할증", 그 사이 "업종 평균권".
   대상 EPS 가 0 이하라 PER 이 없으면 "적자 — PER 비교 불가"로 쓴다.
2. **수익성**: ROE 가 업종 중앙값 이상이면 우위. ROE 15% 이상은 우량 구간으로 표시.
3. **성장 가속**: 분기 영업이익 증가율이 최근 3개 분기 연속 높아지면 "가속", 두 분기 연속 둔화면 "감속".
4. **재무 안정성**: 부채비율 200% 초과는 경고, 100% 이하는 양호.
5. **표본 수**가 5개 미만이면 업종 비교 신뢰도가 낮다고 밝힌다.

## 주의
- 유보율은 수집하지 않으므로 언급하지 않는다.
- 금융업(은행·보험·증권)은 부채비율 기준을 적용하지 않는다.
- 숫자를 다시 계산하지 말고 주어진 값과 괴리율을 인용한다.

## 출력 지침
- 항목별 한 줄 판정 + 종합 등급(우수/보통/주의) 하나.
